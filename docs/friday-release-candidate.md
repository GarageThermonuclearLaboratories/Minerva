## Reproduce

Use Node 24 and Python 3.11 or later without Python optimization. Install pinned packages with `npm ci` and `python3 -m pip install -r requirements.txt`. Restore the split archive with `python3 scripts/restore_sources.py`. Then run `python3 scripts/validate_release_candidate.py --write` to regenerate builder evidence and the manifest from all suites. Run without `--write` to verify the recorded candidate without changing evidence. The static Site is versioned directly in `dist`; no separate compilation step is required. Do not regenerate processing bundles or relabel a comparison baseline to conceal changes.
